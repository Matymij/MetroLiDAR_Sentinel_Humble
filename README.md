# MetroLiDAR Sentinel — ROS 2 Humble

Engineering baseline for 3D-LiDAR obstacle detection in a metro tunnel. The implementation is designed around the official case requirements: Ubuntu 22.04, ROS 2 Humble, Docker, ROS 2 bag input, real-time processing, obstacle distance, generalization and reproducible startup.

See `README_RU.md` for the full Russian guide.
