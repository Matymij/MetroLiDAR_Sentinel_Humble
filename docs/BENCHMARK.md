## Ограничения производительности

1. **Docker Desktop on Windows** — флуктуация CPU 20–30 %.
2. **Чтение bag через bind-mount** → в 2× быстрее, если копировать в `/tmp` контейнера.
3. **Python GIL** — 90 % pipeline в numba (`nogil=True`), оставшиеся 10 % держат GIL.
4. **Потолок Python** — ~55–70 fps. Для 100+ fps нужен C++.

## Ускорение относительно baseline

**v11 = 26× быстрее v1** (1.8 → 47 fps). Основные источники:
- numba JIT (voxel, DBSCAN, rotate, bbox)
- ThreadPoolExecutor (numba отпускает GIL)
- Grid DBSCAN вместо scipy cKDTree
- Универсальный парсер PointCloud2 через np.frombuffer
